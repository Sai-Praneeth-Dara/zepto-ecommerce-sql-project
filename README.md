# 🛒 Zepto E-commerce SQL Data Analysis

## 📌 Project Overview
This project explores Zepto's e-commerce inventory dataset using SQL in MySQL Workbench. It covers data exploration, data-quality checks, price conversion, and business analysis.

## 🎯 Objectives
- Explore product categories and inventory.
- Identify potential data-quality issues.
- Convert product prices from paise to rupees where required.
- Analyze discounts, product availability, and inventory value.
- Generate insights using SQL queries.

## 🛠️ Tools Used
- MySQL
- MySQL Workbench
- SQL
- GitHub

## 📂 Project Structure
- `sql/01_data_exploration.sql` — Initial data exploration
- `sql/02_data_cleaning.sql` — Data-quality checks
- `sql/03_price_conversion.sql` — Price conversion
- `sql/04_business_analysis.sql` — Business analysis queries

## 📊 Business Analysis
The project includes eight business questions covering:
1. Best-value products by discount
2. High-MRP products that are out of stock
3. Estimated inventory revenue by category
4. Products with high MRP and low discounts
5. Categories with the highest average discounts
6. Price-per-gram comparisons
7. Product weight classification
8. Total inventory weight by category

## 🚀 How to Use
1. Install MySQL and MySQL Workbench.
2. Import the Zepto dataset into a database named `zepto_db`.
3. Ensure the table is named `zepto_v2` and its columns match the SQL scripts.
4. Open the SQL files in MySQL Workbench and execute the queries in order.
5. Review the results and interpret the business insights.
